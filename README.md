# مدرّس الأورج (Android overlay)
1. افتح المجلد في Android Studio (Hedgehog أو أحدث) واستنى الـ Gradle Sync.
2. وصّل موبايلك (Developer options + USB debugging) واضغط Run.
3. من التطبيق: "تفعيل الخدمة" ← فعّل "مدرّس الأورج".
   (لو أندرويد 13+ ومنع الخدمة: Settings > Apps > مدرّس الأورج > ⋮ > Allow restricted settings.)
4. افتح تطبيق الأورج بالعرض، دوس "معايرة" في اللوحة، ثم ابدأ الدرس.
